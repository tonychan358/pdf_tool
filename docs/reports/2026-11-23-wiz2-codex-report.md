# PDF 工具箱精靈改版 — 第二批

日期：2026-11-23。範圍：計劃 Task 5、6、7。所有修改限目前專案副本，沒有 commit 或部署。

## 交付結果

七個工具均使用三步精靈：上載 → 各工具設定 → 下載。原有選項、拆分預覽表、頁面縮圖均留在第二步，並提供工具摘要、返回上載及主要處理按鈕。

單一 PDF 結果使用共用完成頁，提供工具專屬標題、下載檔名、可取消的預先壓縮、下載及接力。拆分產生多個 PDF 時，只顯示檔案數與下載 ZIP；只有一份結果時，沿用單一 PDF 完成頁。第二步已移除單一輸出的檔名欄；拆分名單及命名模式仍保留，因為它們決定 ZIP 內每份檔案的名稱。

接力保留壓縮前的原始處理結果及使用者修改的下載檔名。IndexedDB 每次使用獨立識別碼，讀取與刪除在同一交易完成；一小時過期並刪除，寫入時亦清理遺留的過期記錄。目標頁經正常檔案同步／載入路徑帶入，顯示可即時切語言的提示。三張目標卡為批改留白、N-up、頁面編輯，排除目前工具；圖片轉 PDF 不作接力目標。讀寫失敗、遺失、過期及不支援的接力均有雙語訊息。
